How to launch the Astro website
For local preview, unzip the project, install Node 24, open a terminal in astro-project and run:
npm ci
npm run build
npm run preview
For staging, connect GitHub, select a dedicated repository, prepare and review the changes, then upload. The included GitHub Actions workflow builds Astro and deploys to GitHub Pages. The app shows the deployment link and staging address. No production custom domain is configured.
